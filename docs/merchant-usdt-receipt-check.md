## 商家为什么需要核对 USDT 到账？

USDT 收款场景中，到账确认非常重要。

如果确认太早，可能出现未到账就放行服务的问题。
如果确认太慢，又可能影响用户体验和订单处理效率。

商家经常会遇到这些情况：

* 用户发来转账截图，但钱包没有到账
* 用户说已经付款，但查不到交易记录
* 用户转错地址
* 用户转错链
* 用户转账金额不一致
* 多个用户同时付款，订单不好匹配
* 客服需要快速判断是否到账
* 财务需要统计地址收入和支出

因此，商家不能只依赖截图，而应该通过链上记录进行核验。

## 核对 USDT 收款时应该看什么？

商家核对 USDT 到账时，建议重点看 5 个信息：

| 核对项  | 说明           |
| ---- | ------------ |
| 收款地址 | 是否为商家的正确收款地址 |
| 交易方向 | 是否为转入        |
| 转账金额 | 是否和订单金额一致    |
| 转账时间 | 是否和用户付款时间接近  |
| 交易明细 | 是否存在真实链上记录   |

如果这 5 个信息都能对应上，才更适合确认该笔 USDT 已到账。

## 为什么不能只看用户截图？

转账截图只能作为参考，不能作为最终凭证。

常见风险包括：

* 截图可能不是当前订单
* 截图可能是旧交易
* 截图金额相似但不是同一笔
* 截图只显示转出，不代表转入商家地址
* 截图可能被裁剪或修改
* 用户可能转错链或转错地址

对于商家来说，真正可靠的是链上交易记录和收款地址明细。

一句话：

> 商家核账，不看截图定结果，要看链上明细。

## 多笔订单同时付款怎么核对？

如果商家同时收到多笔 USDT 付款，建议按照以下顺序核对：

1. 先看收款地址最近交易记录
2. 按时间筛选最近转入
3. 核对每笔金额
4. 对应用户订单时间
5. 遇到相同金额时继续核对地址和时间
6. 必要时让用户提供 TxHash 辅助定位

如果只靠截图或用户口述，很容易把不同订单混淆。
